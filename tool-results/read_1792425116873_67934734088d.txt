  6116→## 🏗️ تحويل الأتوكاد والريفرت — التفاصيل
  6117→
  6118→### DXF → PDF (يعمل فوراً ✓)
  6119→محلي بالكامل — المخططات (Layouts) مع الإطارات والعناوين تُصدَّر كصفحات PDF.
  6120→```json
  6121→{"spaces": "layouts"}   ← لوحات التخطيط (الافتراضي — مثل ما تراه في AutoCAD)
  6122→{"spaces": "model"}     ← مساحة النموذج
  6123→{"spaces": "all"}       ← كل شيء
  6124→```
  6125→
  6126→### DWG → PDF (سلسلة حلول ذكية)
  6127→1. **AutoCAD مثبت؟** → يُستخدم مباشرة (COM) — أعلى جودة ممكنة ✓
  6128→2. **ODA File Converter؟** (مجاني — [opendesign.com](https://www.opendesign.com/guestfiles/oda_file_converter)) → DWG→DXF ثم PDF ✓
  6129→3. **APS سحابي؟** → التحويل عبر سحابة Autodesk ✓
  6130→4. غير متوفر؟ → رسالة تشرح الخيارات بوضوح
  6131→
  6132→### RVT → PDF (ريفرت)
  6133→ملفات RVT مغلقة تماماً (لا توجد مكتبة مفتوحة تقرأها) — الخياران:
  6134→
  6135→| الخيار | الطريقة | الميزة |
  6136→|---|---|---|
  6137→| **سحابي (APS)** | ضع `APS_CLIENT_ID` + `APS_CLIENT_SECRET` | من أي جهاز — مجاني ([aps.autodesk.com](https://aps.autodesk.com)) |
  6138→| **سكربت Revit** | `pyrevit_export_pdf.py` المرفق | بدون إنترنت — من داخل Revit نفسه |
  6139→
  6140→السكربت المرفق يصدّر **كل مخططات المشروع (Sheets)** إلى PDF:
  6141→- PDF مستقل لكل مخطط + ملف مدموج واحد للمنشأ كاملاً
  6142→- يعمل عبر pyRevit أو Macros داخل Revit (التعليمات داخل الملف)
