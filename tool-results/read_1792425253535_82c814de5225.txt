    20→## 2) المشكلة والحل
    21→
    22→**المشكلة:** أدوات PDF المنتشرة إما إنجليزية، أو مبعثرة في عشرات المواقع، أو مدفوعة، أو بواجهات فوضوية وأوضاع داكنة مزعجة. المستخدم العربي يريد: ارفع ← اكتب ما تريد بكلام عادي ← نزّل النتيجة.
    23→
    24→**الحل:** موقع + أداة MCP واحدة تحتوي **كل شيء**:
    25→- معالجة PDF كاملة (دمج، ضغط، استخراج، ترقيم، علامات مائية، تشفير، Word، صور، كتيّبات...)
    26→- تحويل ملفات التصميم CAD (DXF مباشرة، DWG/RVT عبر Autodesk APS)
    27→- **محرك فهم أوامر عربي هجين**: يفهم الفصحى والمصرية والخليجية والشامية + الأخطاء الإملائية، ويحوّل جملة مثل «ادمج الملفات ثم صغّر حجمها» إلى خطوات تنفيذ فعلية
    28→- طبقة «هل تقصد؟» عند عدم الوضوح + وصفات/مهام شائعة ذكية حسب الملفات المرفوعة
    29→- مطابقة الخطوط العربية (يُخرج PDF بخط المستند الأصلي) + OCR بتمريرين للملفات الممسوحة

    47→## 4) القيود الثابتة — قواعد غير قابلة للمس ⚠️
    48→
    49→1. **كل شيء بالعربية** — الواجهة، الرسائل، الأخطاء، التوضيحات، حتى أسماء الملفات المُنزَّلة. التواصل مع المستخدم صاحب المشروع بالعربية أيضاً.
    50→2. **لا دارك مود إطلاقاً** — ثيم فاتح فقط (`#F4F6FB` خلفية، بطاقات بيضاء، أزرق `#4F55E3`)، ولا زر للتبديل للوضع الداكن.
    51→3. **الواجهة منظمة وليست عشوائية** — تدفق مرقّم واضح: **١ الملفات ← ٢ الخطوات ← ٣ مهام شائعة**، مع شريط أمر ذكي في الأعلى.
    52→4. **لغة السوق لا اللغة التقنية** — كل مصطلح تقني يُترجم لعبارة يفهمها المستخدم العادي (انظر جدول القسم 12).
    53→5. **الحلول مبتكرة وغير تقليدية** (محرك اللهجات، «هل تقصد؟»، الوصفات الذكية، مطابقة الخطوط) **وفي نفس الوقت الأسهل والمجاني والأونلاين**.
    54→6. النواة الأساسية تعمل **بدون أي قاعدة بيانات وبدون مفاتيح API** — الذكاء الاحتياطي (Groq/Gemini مجاني) اختياري، والاشتراكات تُدار في طبقة منفصلة.
    55→7. ملفات المستخدم في نسخة الويب العامة **لا تُخزَّن** (Stateless على Vercel) — الخصوصية ميزة تسويقية.

    84→## 6) المحركات الأساسية ⚙️
    85→
    86→### أ) pdf_engine.py — محرك PDF
    87→- **الصيغ:** PyMuPDF (فتح، تعديل، عرض) + pypdf (دمج/تقسيم/تشفير) + Pillow (صور) + reportlab (توليد).
    88→- **العمليات:** دمج، ضغط 3 مستويات، استخراج/حذف/تدوير/ترتيب صفحات، علامة مائية، ترقيم، تشفير/فك، PDF↔صور، استخراج نص، PDF→Word (pdf2docx اختياري)، تسطيح، N-up، كتيّب، صور→PDF.
    89→- **OCR بتمريرين (مبتكر):** تمرير 1: استخراج/تصحيح (deskew) + Tesseract `ara+eng` ← تمرير 2: إعادة المعالجة بجودة أعلى ودمج الطبقات. تحسين تلقائي: deskew + denoise + adaptive threshold.
    90→- **مطابقة الخطوط (مبتكر):** `font=auto` يستخرج خط المستند الأصلي (`doc.extract_font`) ويستخدمه؛ العربي يُرسم صورة PIL بدقة 300dpi بالخط المطابق + **طبقة بحث مخفية**: كل كلمة تُدرج بـ `word[::-1]` مع `render_mode=3` (غير مرئية) ← البحث في PDF الناتج يجدها بالعربية. `_FONT_REGISTRY`: naskh/amiri/kufi/tajawal/cairo/.../times/arial + أي TTF يمرره المستخدم.
    91→- **إدراج نص عربي مزخرف:** `_insert_styled_text` (الحل الفائز المعتمد).
    92→
    93→### ب) cad_engine.py — محرك CAD
    94→- **DXF → PDF** مباشرة: ezdxf لتحليل + matplotlib للرسم (طبقات، ألوان AutoCAD، extents fit، هوامش).
    95→- **DWG / RVT → PDF** عبر Autodesk APS (Model Derivative) عند توفر `APS_CLIENT_ID/SECRET`، وإلا رسالة عربية واضحة.
    96→- مصغّرات لملفات CAD، معاينة 2up/4up/booklet.
    97→
    98→### ج) interpreter.py — المحرك الهجين للفهم (الميزة الأذكى)
    99→- **المستوى 1 (مجاني فوري):** تطبيع عميق (أ/إ/آ، ة/ه، تشكيل، أرقام هندية) + قاموس نوايا ضخم regex (فصحى + مصري + خليجي + شامي) + كلمات مفردة + **بحث ضبابي للأخطاء الإملائية** («اضعط» → اضغط).
   100→- **تفكيك الجمل المركبة:** «شيل الصفحة التانية ورقمهالهم» ← خطوتان (يجرّب كل «و» ويقطع حيث تفهم كل جهة كأمر مستقل — حذر لأن «واحد» تبدأ بـ و!).
   101→- **استخراج المعطيات:** نطاقات صفحات بكل الصيغ («من 2 لحد 5», «1-3,5»)، زاوية الدوران، كلمة المرور، نص الختم (مسودة/سري/معتمد)، مستوى الضغط (أقصى/خفيف).
   102→- **طبقة «هل تقصد؟»:** عندما يشكك في الفهم، تقترح أقرب الأوامر.
   103→- **المستوى 2 (اختياري مجاني):** Groq/Gemini (OpenAI-compatible) عند الحيرة — بدون مفتاح تكفي القواعد.
   104→- **الوصفات الذكية:** حسب أنواع الملفات المرفوعة (PDF ممسوح → OCR، صور → مستند، CAD → PDF...).
   105→- **مخرجات التفسير بالعربية السوقية:** «دمج 2 ملفات ← تصغير الحجم (قوي) ← ترقيم الصفحات».

   109→## 7) واجهة برمجية — كل المسارات (النسخة المحلية الحولية)
   110→
   111→| المسار | الدور |
   112→|---|---|
   113→| `POST /api/files` (multipart) | رفع ← `{files:[{id,name,kind,pages,size,scanned,...}]}` |
   114→| `GET /api/files/{fid}/thumb?page&dpi` | مصغّرة PNG |
   115→| `GET /api/files/{fid}/download` | تحميل |
   116→| `DELETE /api/files/{fid}` | حذف |
   117→| `POST /api/interpret` `{text,file_ids,mode}` | تفسير عربي ← `{steps[],explanation,confidence,engine,unknown,recipes}` |
   118→| `POST /api/run` `{steps:[{op,inputs,params,label}]}` | تنفيذ سلسلة ← `{results:[{step,op,duration,outputs[]}]}` |
   119→| `POST /api/print-preview` `{file_id,mode}` | معاينة طباعة 2up/4up/booklet |
   120→| `GET /api/recipes` | مهام شائعة حسب الملفات المرفوعة |
   121→| `GET /api/history` | آخر 30 عملية |
   122→| `GET /api/ops` | قائمة 31 عملية |
   123→| `GET /api/health` | الحالة |
   124→

   141→## 10) نسخة Vercel (Stateless) ☁️
   142→
   143→- `api/index.py` بدون أي حالة بين الطلبات: `/api/inspect` (فحص بالمتصفح) · `/api/interpret` · `/api/run` يستقبل ملفات+خطوات multipart ويرجع **ZIP** فيه كل المخرجات + `manifest.json` · `/api/thumb`.
   144→- `public/index.html`: الملفات **تبقى في متصفح المستخدم** (الخصوصية + تجاوز حد 4.5MB) وتُرسل عند التنفيذ فقط.
   145→- `vercel.json`: builds + routes + functions (memory 1024MB, maxDuration 120s).
   146→- **قيود Vercel وحلولها:** لا Tesseract (system binaries) → OCR يُعطَّل في هذه النسخة برسالة واضحة · طلبات ≤4.5MB → الملفات في المتصفح · لا ذاكرة مشتركة → Stateless.
   147→- النشر: `npm i -g vercel && cp requirements-vercel.txt requirements.txt && vercel --prod`.

   159→## 12) قواعد اللغة — من التقني إلى سوق 🗣️
   160→
   161→| ❌ لا تستخدم | ✅ استخدم |
   162→|---|---|
   163→| خط العمل / Workflow / خط أنابيب | **الخطوات** |
   164→| ضغط (medium/strong) | **تصغير الحجم (متوسط/قوي)** |
   165→| تسطيح نهائي | **تثبيت نهائي** |
   166→| تشفير | **حماية بكلمة مرور** |
   167→| DPI | **دقة الصورة** |
   168→| صفحات في ورقة | **عدة صفحات في الورقة** |
   169→| سكان / scan | **ممسوح ضوئياً** |
   170→| تفعيل OCR (نص مخفي) | **تفعيل التعرّف الضوئي (نص قابل للبحث)** |
   171→| وصفات سريعة | **مهام شائعة** |
   172→| حزمة الوثائق / نسخة رسمية / جاهز للإيميل | **تجميع المستندات / مستند رسمي / جاهز للإرسال** |
   173→| الأمر الذكي | **اكتب طلبك هنا… مثلاً: «ادمج الملفات ثم صغّر حجمها»** |
   174→| خط أنابيب فارغ (خطأ) | **أضف خطوة واحدة على الأقل** |
   175→| ارفع ملفات اولاً | **أضف ملفاتك أولاً** |
   176→
   177→**العد العربي الصحيح:** ملف واحد / ملفان / 3 ملفات / 15 ملفًا — وكذلك خطوة/خطوتان/خطوات.
   178→**أسماء الصيغ تبقى كما هي:** PDF · Word · DXF · DWG · RVT · PNG (أسماء عالمية يفهمها الجميع).

   182→## 13) الواجهة — المواصفات البصرية 🎨
   183→
   184→- **ثيم فاتح فقط:** خلفية `#F4F6FB`، بطاقات `#FFFFFF`، نص `#1B2438`، أزرق العلامة `#4F55E3`، ظلال ناعمة، حواف 12-14px.
   185→- **البنية:** أعلى = الهوية + شريط الحالة · ثم **شريط الأمر الذكي** (🧠 اكتب طلبك ← «اقترح الخطوات ✦» ← «تنفيذ ⚡») · ثم 3 أعمدة: **١ الملفات** (رفع + مصغّرات + وسوم) | **٢ الخطوات** (مرقّمة مع ↑↓ و✕ وحقول عربية) | **٣ مهام شائعة + ملاحظات**.
   186→- **الخط:** Segoe UI / Noto Sans Arabic / Tajawal.
   187→- **التنبيهات:** بطاقات منزلقة أسفل اليمين (نجاح أخضر/خطأ أحمر) — كلها بالعربية.
   188→- **كشف الانقطاع:** شريط تحذير يشرح الفرق بين «معاينة الملف» (بلا شبكة) و«المعاينة المباشرة» + زر إعادة المحاولة.
   189→- أزرار معاينة الطباعة 🖨️ على كل ملف PDF.

   193→## 14) معايير القبول ✅
   194→
   195→1. المستخدم يرفع PDF/صور/CAD ← مصغّرات ووسوم (نوع/صفحات/ممسوح) تظهر فوراً.
   196→2. يكتب «ادمج الملفات ثم صغّر حجمها بقوة» ← خطوات مبنية بالعربية: «دمج 2 ملفات ← تصغير الحجم (قوي)».
   197→3. «هل تقصد؟» تظهر عند الكلام الغامض، والوصفات الذكية تتغير حسب الملفات.
   198→4. تنفيذ سلسلة كاملة ← نتائج صحيحة (مخرج لكل خطوة) ← تحميل مباشر.
   199→5. البحث داخل PDF العربي المُولَّد بخط مطابق يجد الكلمات (طبقة `word[::-1]`).
   200→6. **لا كلمة غير عربية مفهومة** في الواجهة (راجع جدول القسم 12) — و**لا دارك مود** — و**البنية مرقّمة منظمة**.
   201→7. نسخة Vercel تعمل Stateless بالكامل (فحص ← تفسير ← تنفيذ → ZIP).
   202→8. كل الأخطاء والرسائل بالعربية وبصياغة السوق.

   253→def _p(path: str | os.PathLike) -> Path:
   254→    """تحويل المسار إلى Path مطلق والتحقق من وجوده."""
   255→    path = Path(path).expanduser()

   257→        raise PDFEngineError(f"الملف غير موجود: {path}")
   258→    return path.resolve()

   261→def _out(path: str | os.PathLike) -> Path:
   262→    """تحضير مسار الإخراج: إنشاء المجلد الأب وإرجاع Path مطلق."""
   263→    path = Path(path).expanduser().resolve()
   264→    path.parent.mkdir(parents=True, exist_ok=True)
   265→    return path

   268→def _new_path(output: str | os.PathLike, default_name: str, default_dir: str | None = None) -> Path:
   269→    """إذا كان output مجلداً (أو فارغاً) نولّد اسماً افتراضياً بداخله."""
   270→    if output:
   271→        path = Path(output).expanduser()
   272→        if str(output).endswith(("/", "\\")) or (path.exists() and path.is_dir()):
   273→            path = path / default_name
   274→        return _out(path)
   275→    return _out(Path(default_dir or ".") / default_name)

   278→def parse_pages(spec: str | None, total: int) -> list[int]:
   279→    """
   280→    تحويل مواصفات الصفحات إلى فهارس صفرية.
   281→    الأمثلة المدعومة (الترقيم يبدأ من 1 كما يراه المستخدم):
   282→        "all" أو "" أو None   -> كل الصفحات
   283→        "3"                   -> الصفحة 3 فقط
   284→        "1-3,5,7-9"           -> نطاقات مفصولة بفواصل
   285→        "2-"                  -> من 2 حتى النهاية
   286→        "-4"                  -> من البداية حتى 4
   287→    """
   288→    if total <= 0:
   289→        raise PDFEngineError("ملف PDF لا يحتوي على صفحات.")
   290→
   291→    if spec is None or str(spec).strip() == "" or str(spec).strip().lower() == "all":
   292→        return list(range(total))
   293→
   294→    pages: set[int] = set()
   295→    for token in str(spec).split(","):
   296→        token = token.strip()
   297→        if not token:
   298→            continue
   299→        m = re.fullmatch(r"(\d*)\s*-\s*(\d*)", token)
   300→        if m:
   301→            start_s, end_s = m.group(1), m.group(2)
   302→            if not start_s and not end_s:
   303→                raise PDFEngineError(f"نطاق غير صالح: '{token}'")
   304→            start = int(start_s) if start_s else 1
   305→            end = int(end_s) if end_s else total
   306→            if start < 1 or end > total or start > end:
   307→                raise PDFEngineError(f"النطاق '{token}' خارج حدود الملف (1-{total}).")
   308→            pages.update(range(start - 1, end))
   309→        elif token.isdigit():
   310→            n = int(token)
   311→            if n < 1 or n > total:
   312→                raise PDFEngineError(f"رقم الصفحة '{n}' خارج حدود الملف (1-{total}).")
   313→            pages.add(n - 1)
   314→        else:
   315→            raise PDFEngineError(f"وصف صفحات غير صالح: '{token}'")
   316→
   317→    if not pages:
   318→        raise PDFEngineError("لم يتم تحديد أي صفحة صالحة.")
   319→    return sorted(pages)
   320→
   321→
   322→def _group_pages(spec: str | None, total: int) -> list[list[int]]:
   323→    """مثل parse_pages لكن يحافظ على تجميع النطاقات (كل نطاق = مجموعة)."""
   324→    if spec is None or str(spec).strip() == "" or str(spec).strip().lower() == "all":
   325→        return [list(range(total))]
   326→    groups: list[list[int]] = []
   327→    for token in str(spec).split(","):
   328→        token = token.strip()
   329→        if token:
   330→            groups.append(parse_pages(token, total))
   331→    if not groups:
   332→        raise PDFEngineError("لم يتم تحديد أي نطاق صفحات.")
   333→    return groups

   336→def _fmt_size(n: int | float) -> str:
   337→    n = float(n)
   338→    for unit in ("B", "KB", "MB", "GB"):
   339→        if n < 1024 or unit == "GB":
   340→            return f"{n:.1f} {unit}" if unit != "B" else f"{int(n)} B"
   341→        n /= 1024
   342→    return f"{n:.1f} GB"

   345→def _human_bytes(before: int, after: int) -> dict[str, Any]:
   346→    saved = before - after
   347→    pct = (saved / before * 100) if before else 0.0
   348→    return {
   349→        "before_bytes": before,
   350→        "after_bytes": after,
   351→        "before_human": _fmt_size(before),
   352→        "after_human": _fmt_size(after),
   353→        "saved_bytes": max(saved, 0),
   354→        "saved_percent": round(max(pct, 0.0), 1),
   355→    }

   363→def pdf_info(path: str) -> dict[str, Any]:
   364→    """معلومات شاملة عن ملف PDF: عدد الصفحات، المقاسات، البيانات الوصفية، التشفير..."""
   365→    p = _p(path)
   366→    reader = PdfReader(str(p))
   367→    encrypted = reader.is_encrypted
   368→    meta = reader.metadata or {}
   369→
   370→    sizes: list[dict[str, Any]] = []
   371→    try:
   372→        for i, page in enumerate(reader.pages):
   373→            box = page.mediabox
   374→            sizes.append({
   375→                "page": i + 1,
   376→                "width_pt": round(float(box.width), 1),
   377→                "height_pt": round(float(box.height), 1),
   378→            })
   379→    except Exception:
   380→        sizes = []
   381→
   382→    return {
   383→        "file": str(p),
   384→        "file_size_bytes": p.stat().st_size,
   385→        "file_size_human": _fmt_size(p.stat().st_size),
   386→        "pages": len(reader.pages),
   387→        "encrypted": bool(encrypted),
   388→        "metadata": {
   389→            "title": meta.get("/Title"),
   390→            "author": meta.get("/Author"),
   391→            "subject": meta.get("/Subject"),
   392→            "creator": meta.get("/Creator"),
   393→            "producer": meta.get("/Producer"),
   394→            "creation_date": str(meta.get("/CreationDate") or ""),
   395→        },
   396→        "page_sizes": sizes[:20],  # أول 20 صفحة فقط للإيجاز
   397→    }

   411→def pdf_merge(inputs: Sequence[str], output: str) -> dict[str, Any]:
   412→    """دمج عدة ملفات PDF في ملف واحد (بنفس الترتيب المُعطى)."""
   413→    if not inputs:
   414→        raise PDFEngineError("يجب تحديد ملف واحد على الأقل للدمج.")
   415→    out = _out(output)
   416→    writer = PdfWriter()
   417→    total_pages = 0
   418→    merged: list[str] = []
   419→
   420→    for src in inputs:
   421→        sp = _p(src)
   422→        reader = PdfReader(str(sp))
   423→        for page in reader.pages:
   424→            writer.add_page(page)
   425→        total_pages += len(reader.pages)
   426→        merged.append(str(sp))
   427→
   428→    with open(out, "wb") as f:
   429→        writer.write(f)
   430→
   431→    return {
   432→        "success": True,
   433→        "output": str(out),
   434→        "output_size_human": _fmt_size(out.stat().st_size),
   435→        "input_files": merged,
   436→        "total_pages": total_pages,
   437→    }

   440→def pdf_split(
   441→    path: str,
   442→    output_dir: str,
   443→    every_n_pages: int | None = None,
   444→    ranges: Sequence[str] | None = None,
   445→) -> dict[str, Any]:
   446→    """
   447→    فصل ملف PDF إلى عدة ملفات:
   448→      - every_n_pages: كل N صفحات في ملف (الافتراضي 1 = كل صفحة لوحدها)
   449→      - ranges: قائمة نطاقات مثل ["1-3", "4-10", "11-"] — لكل نطاق ملف
   450→    """
   451→    p = _p(path)
   452→    odir = Path(output_dir).expanduser().resolve()
   453→    odir.mkdir(parents=True, exist_ok=True)
   454→
   455→    reader = PdfReader(str(p))
   456→    total = len(reader.pages)
   457→    stem = p.stem
   458→    outputs: list[str] = []
   459→
   460→    if ranges:
   461→        for i, group in enumerate(_group_pages(",".join(ranges), total), start=1):
   462→            writer = PdfWriter()
   463→            for idx in group:
   464→                writer.add_page(reader.pages[idx])
   465→            name = f"{stem}_part{i:02d}_p{group[0]+1}-{group[-1]+1}.pdf"
   466→            out = odir / name
   467→            with open(out, "wb") as f:
   468→                writer.write(f)
   469→            outputs.append(str(out))
   470→    else:
   471→        n = int(every_n_pages or 1)
   472→        if n < 1:
   473→            raise PDFEngineError("every_n_pages يجب أن يكون 1 أو أكثر.")
   474→        part = 0
   475→        for start in range(0, total, n):
   476→            part += 1
   477→            writer = PdfWriter()
   478→            end = min(start + n, total)
   479→            for idx in range(start, end):
   480→                writer.add_page(reader.pages[idx])
   481→            name = f"{stem}_part{part:02d}_p{start+1}-{end}.pdf"
   482→            out = odir / name
   483→            with open(out, "wb") as f:
   484→                writer.write(f)
   485→            outputs.append(str(out))
   486→
   487→    return {
   488→        "success": True,
   489→        "source": str(p),
   490→        "total_pages": total,
   491→        "files_created": len(outputs),
   492→        "outputs": outputs,
   493→    }

   519→def pdf_delete_pages(path: str, pages: str, output: str) -> dict[str, Any]:
   520→    """حذف صفحات محددة من ملف PDF (مثال: pages='2,5-7')."""
   521→    p = _p(path)
   522→    out = _new_path(output, f"{p.stem}_deleted.pdf")

   524→    total = len(reader.pages)

   528→        raise PDFEngineError("لا يمكن حذف كل الصفحات — احتفظ بصفحة واحدة على الأقل.")
   529→
   530→    writer = PdfWriter()
   531→    for i in keep:
   532→        writer.add_page(reader.pages[i])
   533→
   534→    with open(out, "wb") as f:
   535→        writer.write(f)
   536→
   537→    return {
   538→        "success": True,
   539→        "output": str(out),
   540→        "deleted_pages": sorted(i + 1 for i in to_delete),
   541→        "remaining_pages": len(keep),
   542→    }

   545→def pdf_reorder_pages(path: str, order: str, output: str) -> dict[str, Any]:
   546→    """
   547→    إعادة ترتيب الصفحات و/أو تكرارها.
   548→    مثال: order='3,1,1,2' -> الصفحة 3 أولاً، ثم 1 مرتين، ثم 2.

   550→    p = _p(path)
   551→    out = _new_path(output, f"{p.stem}_reordered.pdf")

   553→    idxs = parse_pages(order, len(reader.pages))  # parse_pages يقبل التكرار هنا عبر split يدوي

   555→    # parse_pages تُزيل التكرارات، نحتاج الترتيب الحرفي:

   564→    for i in manual:
   565→        writer.add_page(reader.pages[i])
   566→
   567→    with open(out, "wb") as f:
   568→        writer.write(f)
   569→
   570→    return {
   571→        "success": True,
   572→        "output": str(out),
   573→        "new_order": [i + 1 for i in manual],
   574→        "pages_count": len(manual),

   583→def pdf_rotate(path: str, degrees: int, output: str, pages: str | None = None) -> dict[str, Any]:
   584→    """تدوير صفحات PDF بزاوية 90/180/270 (كل الصفحات أو صفحات محددة)."""
   585→    if degrees % 90 != 0:
   586→        raise PDFEngineError("الزاوية يجب أن تكون من مضاعفات 90 (90 أو 180 أو 270).")
   587→    p = _p(path)
   588→    out = _new_path(output, f"{p.stem}_rotated.pdf")
   589→    reader = PdfReader(str(p))
   590→    total = len(reader.pages)
   591→    targets = set(parse_pages(pages, total))
   592→
   593→    writer = PdfWriter()
   594→    for i, page in enumerate(reader.pages):
   595→        if i in targets:
   596→            page.rotate(degrees % 360)
   597→        writer.add_page(page)
   598→
   599→    with open(out, "wb") as f:
   600→        writer.write(f)
   601→
   602→    return {
   603→        "success": True,
   604→        "output": str(out),
   605→        "rotated_pages": sorted(i + 1 for i in targets),
   606→        "degrees": degrees % 360,
   607→    }

   610→def pdf_compress(path: str, output: str, level: str = "medium") -> dict[str, Any]:
   611→    """
   612→    ضغط ملف PDF.
   613→    المستويات:
   614→      - light:  تنظيف بسيط وضغط عام (بدون فقدان جودة الصور)
   615→      - medium: تنظيف أعمق + ضغط الصور والخطوط
   616→      - strong: إعادة ترميز الصور بدقة أقل (قد يقلل جودة الصور قليلاً)
   617→    """
   618→    p = _p(path)
   619→    out = _new_path(output, f"{p.stem}_compressed.pdf")
   620→    level = (level or "medium").lower()
   621→    if level not in ("light", "medium", "strong"):
   622→        raise PDFEngineError("المستوى يجب أن يكون: light أو medium أو strong.")
   623→
   624→    doc = pymupdf.open(str(p))
   625→
   626→    if level == "strong":
   627→        # إعادة ترميز الصور المضمنة: أقصى ضلع 1200px وجودة JPEG 60
   628→        max_dim, quality = 1200, 60
   629→        for page in doc:
   630→            for info in page.get_images(full=True):
   631→                xref = info[0]
   632→                try:
   633→                    pix = pymupdf.Pixmap(doc, xref)
   634→                    if pix.alpha:
   635→                        pix = pymupdf.Pixmap(pymupdf.csRGB, pix)
   636→                    elif pix.n - pix.alpha >= 4:  # CMYK -> RGB
   637→                        pix = pymupdf.Pixmap(pymupdf.csRGB, pix)
   638→                    img = Image.frombytes("RGB" if pix.n == 3 else "L", (pix.width, pix.height), pix.samples)
   639→                    if max(img.size) > max_dim:
   640→                        ratio = max_dim / max(img.size)
   641→                        img = img.resize((max(1, int(img.width * ratio)), max(1, int(img.height * ratio))), Image.LANCZOS)
   642→                    buf = io.BytesIO()
   643→                    img.save(buf, "JPEG", quality=quality, optimize=True)
   644→                    page.replace_image(xref, stream=buf.getvalue())
   645→                except Exception:
   646→                    continue  # نتجاوز الصور التي لا يمكن معالجتها
   647→
   648→    save_kwargs: dict[str, Any]
   649→    if level == "light":
   650→        save_kwargs = {"garbage": 1, "deflate": True}
   651→    elif level == "medium":
   652→        save_kwargs = {"garbage": 3, "deflate": True, "clean": True, "deflate_images": True, "deflate_fonts": True}
   653→    else:  # strong
   654→        save_kwargs = {"garbage": 4, "deflate": True, "clean": True, "deflate_images": True, "deflate_fonts": True}
   655→
   656→    try:
   657→        doc.subset_fonts()
   658→    except Exception:
   659→        pass
   660→
   661→    doc.save(str(out), **save_kwargs)
   662→    doc.close()
   663→
   664→    before = p.stat().st_size
   665→    after = out.stat().st_size
   666→    result = {"success": True, "output": str(out), "level": level}
   667→    result.update(_human_bytes(before, after))
   668→    return result
   669→

   676→def pdf_to_images(
   677→    path: str,
   678→    output_dir: str,
   679→    image_format: str = "png",
   680→    dpi: int = 150,
   681→    pages: str | None = None,
   682→) -> dict[str, Any]:
   683→    """تحويل صفحات PDF إلى صور (PNG أو JPG)."""
   684→    p = _p(path)
   685→    odir = Path(output_dir).expanduser().resolve()
   686→    odir.mkdir(parents=True, exist_ok=True)
   687→    fmt = (image_format or "png").lower().lstrip(".")
   688→    if fmt in ("jpg", "jpeg"):
   689→        fmt = "jpg"
   690→    if fmt not in ("png", "jpg"):
   691→        raise PDFEngineError("الصيغة يجب أن تكون png أو jpg.")
   692→    dpi = max(36, min(int(dpi), 600))
   693→
   694→    doc = pymupdf.open(str(p))
   695→    idxs = parse_pages(pages, len(doc))
   696→    mat = pymupdf.Matrix(dpi / 72.0, dpi / 72.0)
   697→    outputs: list[str] = []
   698→
   699→    for i in idxs:
   700→        pix = doc[i].get_pixmap(matrix=mat, alpha=False)
   701→        name = f"{p.stem}_page{i+1:03d}.{fmt}"

   703→        if fmt == "jpg":

   705→        else:
   706→            pix.save(str(out))
   707→        outputs.append(str(out))
   708→
   709→    return {
   710→        "success": True,
   711→        "source": str(p),
   712→        "dpi": dpi,
   713→        "format": fmt,
   714→        "files_created": len(outputs),

   719→def images_to_pdf(images: Sequence[str], output: str, page_size: str | "None" = None) -> dict[str, Any]:
   720→    """
   721→    دمج صور (PNG/JPG...) في ملف PDF واحد — كل صورة صفحة.
   722→    page_size: 'image' (حجم الصورة نفسها، الافتراضي) أو 'a4' (تُوَزَّع داخل A4).
   723→    """
   724→    if not images:
   725→        raise PDFEngineError("يجب تحديد صورة واحدة على الأقل.")
   726→    out = _out(output)
   727→    mode = (page_size or "image").lower()
   728→    if mode not in ("image", "a4"):
   729→        raise PDFEngineError("page_size يجب أن تكون image أو a4.")
   730→
   731→    pil_images: list[Image.Image] = []
   732→    for src in images:
   733→        sp = _p(src)
   734→        im = Image.open(sp)
   735→        if im.mode in ("RGBA", "P", "LA"):
   736→            im = im.convert("RGB")
   737→        elif im.mode != "RGB":
   738→            im = im.convert("RGB")
   739→        if mode == "a4":
   740→            a4 = Image.new("RGB", (1240, 1754), "white")  # A4 @ 150dpi
   741→            im.thumbnail((a4.width - 40, a4.height - 40), Image.LANCZOS)
   742→            a4.paste(im, ((a4.width - im.width) // 2, (a4.height - im.height) // 2))
   743→            im = a4
   744→        pil_images.append(im)
   745→
   746→    first, rest = pil_images[0], pil_images[1:]
   747→    first.save(out, "PDF", save_all=True, append_images=rest, resolution=150)
   748→    for im in pil_images:
   749→        im.close()
   750→
   751→    return {
   752→        "success": True,
   753→        "output": str(out),
   754→        "images_count": len(images),
   755→        "output_size_human": _fmt_size(out.stat().st_size),
   756→    }

   813→def _measure_font(size: int, fontfile: str | None = None) -> ImageFont.FreeTypeFont | ImageFont.ImageFont:
   814→    if fontfile and Path(fontfile).exists():
   815→        try:
   816→            return ImageFont.truetype(fontfile, size)
   817→        except Exception:
   818→            pass
   819→    for name in ("DejaVuSans.ttf", "Arial.ttf", "arial.ttf"):
   820→        try:
   821→            return ImageFont.truetype(name, size)
   822→        except Exception:
   823→            continue
   824→    try:
   825→        return ImageFont.load_default(size=size)
   826→    except TypeError:
   827→        return ImageFont.load_default()

   830→def _make_watermark_png(
   831→    width: int,
   832→    height: int,
   833→    text: str,
   834→    angle: float,
   835→    opacity: float,
   836→    font_size: int,
   837→    color: tuple[int, int, int],
   838→    fontfile: str | None = None,
   839→) -> bytes:
   840→    """صناعة صورة علامة مائية شفافة بنص مائل — بالخط المطلوب إن وُجد."""
   841→    layer = Image.new("RGBA", (width, height), (0, 0, 0, 0))
   842→    draw = ImageDraw.Draw(layer)
   843→    font = _measure_font(font_size, fontfile)
   844→
   845→    # رسم النص على لوح أصغر ثم تدويره وتكراره
   846→    bbox = draw.textbbox((0, 0), text, font=font)
   847→    tw, th = bbox[2] - bbox[0], bbox[3] - bbox[1]
   848→    txt_img = Image.new("RGBA", (tw + 20, th + 20), (0, 0, 0, 0))
   849→    txt_draw = ImageDraw.Draw(txt_img)
   850→    alpha = int(max(0, min(1, opacity)) * 255)
   851→    txt_draw.text((10, 10), text, font=font, fill=(*color, alpha))
   852→
   853→    rotated = txt_img.rotate(angle, expand=True, resample=Image.BICUBIC)
   854→
   855→    # توزيع النص على الصفحة بنمط شبكي متباعد
   856→    step_x = max(rotated.width + int(width * 0.12), 200)
   857→    step_y = max(rotated.height + int(height * 0.18), 120)
   858→    y = -rotated.height // 2
   859→    row = 0
   860→    while y < height:
   861→        x = (-rotated.width // 2) + (step_x // 2 if row % 2 else 0)
   862→        while x < width:
   863→            layer.alpha_composite(rotated, (x, y))
   864→            x += step_x
   865→        y += step_y
   866→        row += 1
   867→
   868→    buf = io.BytesIO()
   869→    layer.save(buf, "PNG")
   870→    return buf.getvalue()

   873→def pdf_watermark(
   874→    path: str,
   875→    output: str,
   876→    text: str | None = None,
   877→    watermark_pdf: str | None = None,
   878→    opacity: float = 0.18,
   879→    angle: float = 45,
   880→    font_size: int = 42,
   881→    pages: str | None = None,
   882→    font: str | None = None,
   883→) -> dict[str, Any]:
   884→    """
   885→    إضافة علامة مائية:
   886→      - text: نص العلامة المائية (يُرسم بشكل متكرر ومائل)
   887→      - watermark_pdf: أو استخدم الصفحة الأولى من ملف PDF آخر كعلامة مائية
   888→      - font: "naskh"/"amiri"/... أو مسار خط .ttf — لتكون العلامة بنفس خط المستند
   889→    """
   890→    if not text and not watermark_pdf:
   891→        raise PDFEngineError("حدد إما نص العلامة المائية (text) أو ملف PDF (watermark_pdf).")
   892→
   893→    p = _p(path)
   894→    out = _new_path(output, f"{p.stem}_watermarked.pdf")
   895→    doc = pymupdf.open(str(p))
   896→    idxs = set(parse_pages(pages, len(doc)))
   897→    fontfile = find_font_file(font) if font else (_resolve_font(doc, None, "auto") if text else None)
   898→
   899→    stamp_png: bytes | None = None
   900→    if watermark_pdf:
   901→        wp = _p(watermark_pdf)
   902→        wdoc = pymupdf.open(str(wp))
   903→        pix = wdoc[0].get_pixmap(alpha=True)
   904→        stamp_png = pix.tobytes("png")
   905→        wdoc.close()
   906→
   907→    for i in idxs:
   908→        page = doc[i]
   909→        rect = page.rect
   910→        if stamp_png:
   911→            # إدراج صورة العلامة المائية بحجم الصفحة مع الحفاظ على النسب
   912→            page.insert_image(rect, stream=stamp_png, keep_proportion=True, overlay=True)
   913→        else:
   914→            w = max(int(rect.width), 100)
   915→            h = max(int(rect.height), 100)
   916→            # العربي يحتاج تشكيل العرض (bidi) قبل الرسم على الصورة
   917→            draw_text = text or ""
   918→            if _contains_arabic(draw_text):
   919→                try:
   920→                    import arabic_reshaper
   921→                    from bidi.algorithm import get_display
   922→                    draw_text = get_display(arabic_reshaper.ArabicReshaper().reshape(draw_text))
   923→                except Exception:
   924→                    pass
   925→            png = _make_watermark_png(w, h, draw_text, angle, opacity, font_size, (80, 80, 80), fontfile)
   926→            page.insert_image(rect, stream=png, overlay=True)
   927→
   928→    doc.save(str(out), garbage=3, deflate=True)
   929→    doc.close()
   930→
   931→    return {
   932→        "success": True,
   933→        "output": str(out),
   934→        "watermarked_pages": sorted(i + 1 for i in idxs),
   935→        "type": "pdf-stamp" if watermark_pdf else "text",
   936→        "font_used": Path(fontfile).name if fontfile else "default",
   937→    }

   940→def pdf_add_page_numbers(
   941→    path: str,
   942→    output: str,
   943→    start_number: int = 1,
   944→    position: str = "bottom-center",
   945→    font_size: int = 12,
   946→    pages: str | None = None,
   947→) -> dict[str, Any]:
   948→    """إضافة أرقام صفحات إلى PDF. position: bottom-center / bottom-right / bottom-left / top-center."""
   949→    p = _p(path)
   950→    out = _new_path(output, f"{p.stem}_numbered.pdf")
   951→    doc = pymupdf.open(str(p))
   952→    idxs = set(parse_pages(pages, len(doc)))
   953→    pos = (position or "bottom-center").lower()
   954→
   955→    for n, i in enumerate(sorted(idxs), start=start_number):
   956→        page = doc[i]
   957→        rect = page.rect
   958→        label = str(n)
   959→        tw = pymupdf.get_text_length(label, fontsize=font_size)
   960→
   961→        if pos == "bottom-center":
   962→            x, y = (rect.width - tw) / 2, rect.height - 18
   963→        elif pos == "bottom-right":
   964→            x, y = rect.width - tw - 24, rect.height - 18
   965→        elif pos == "bottom-left":
   966→            x, y = 24, rect.height - 18
   967→        elif pos == "top-center":
   968→            x, y = (rect.width - tw) / 2, 28
   969→        else:
   970→            raise PDFEngineError("position غير معروفة — استخدم bottom-center أو bottom-right أو bottom-left أو top-center.")
   971→
   972→        page.insert_text(pymupdf.Point(x, y), label, fontsize=font_size, color=(0, 0, 0))
   973→
   974→    doc.save(str(out), garbage=3, deflate=True)
   975→    doc.close()
   976→
   977→    return {
   978→        "success": True,
   979→        "output": str(out),
   980→        "numbered_pages": sorted(i + 1 for i in idxs),
   981→        "start_number": start_number,
   982→        "position": pos,
   983→    }

   991→def pdf_encrypt(path: str, password: str, output: str) -> dict[str, Any]:
   992→    """تشفير PDF بكلمة مرور (تُطلب عند الفتح)."""
   993→    if not password:
   994→        raise PDFEngineError("كلمة المرور لا يمكن أن تكون فارغة.")
   995→    p = _p(path)
   996→    out = _new_path(output, f"{p.stem}_encrypted.pdf")
   997→    reader = PdfReader(str(p))
   998→    if reader.is_encrypted:
   999→        raise PDFEngineError("الملف مشفّر أصلاً — استخدم pdf_decrypt أولاً.")
  1000→
  1001→    writer = PdfWriter()
  1002→    for page in reader.pages:
  1003→        writer.add_page(page)
  1004→    writer.encrypt(password)
  1005→
  1006→    with open(out, "wb") as f:
  1007→        writer.write(f)
  1008→
  1009→    return {"success": True, "output": str(out), "encrypted": True}

  1069→def pdf_edit_text(
  1070→    path: str,
  1071→    search: str,
  1072→    replace: str,
  1073→    output: str,
  1074→    pages: str | None = None,
  1075→    font: str = "auto",
  1076→) -> dict[str, Any]:
  1077→    """
  1078→    البحث عن نص واستبداله (تعديل النص الموجود فعلياً) — **بنفس خط المستند الأصلي**.
  1079→    font:
  1080→      - "auto"/"match": مطابقة تلقائية — يستخرج الخط الأصلي المدمج في الملف ويستخدمه
  1081→      - "naskh" / "amiri" / "kufi" / "tajawal" / ... : خط من المكتبة
  1082→      - مسار ملف خط (.ttf): خطك الخاص
  1083→    """
  1084→    if not search:
  1085→        raise PDFEngineError("نص البحث لا يمكن أن يكون فارغاً.")
  1086→    p = _p(path)
  1087→    out = _new_path(output, f"{p.stem}_edited.pdf")
  1088→    doc = pymupdf.open(str(p))
  1089→    idxs = set(parse_pages(pages, len(doc)))
  1090→    report = []
  1091→    total_hits = 0
  1092→    fonts_used: set[str] = set()
  1093→
  1094→    for i in sorted(idxs):
  1095→        page = doc[i]
  1096→        hits = _search_text(page, search)
  1097→        if not hits:
  1098→            continue
  1099→        total_hits += len(hits)
  1100→        pending_visible: list[tuple[Any, float, str | None, tuple]] = []
  1101→        image_based = _page_is_image_based(page)
  1102→        for r in hits:
  1103→            style = _span_style_for(page, r)
  1104→            size = (style or {}).get("size") or max(6.0, min(r.height * 0.72, 72.0))
  1105→            color_int = (style or {}).get("color", 0)
  1106→            rgb = (((color_int >> 16) & 255) / 255, ((color_int >> 8) & 255) / 255, (color_int & 255) / 255)
  1107→            fontfile = _resolve_font(doc, (style or {}).get("font"), font)
  1108→            if fontfile:
  1109→                fonts_used.add(Path(fontfile).name)
  1110→            fill = (1, 1, 1) if image_based else False  # مسح ضوئي: تبييض لطمس الصورة
  1111→
  1112→            if replace and _contains_arabic(replace):
  1113→                # اشطب ثم أدرج البديل العربي بشكل مرئي (تشكيل صحيح + الخط المطابق)
  1114→                page.add_redact_annot(r, fill=fill, cross_out=False)
  1115→                pending_visible.append((r, size, fontfile, rgb))
  1116→            else:
  1117→                if fontfile:
  1118→                    # بديل لاتيني بخط مطابق
  1119→                    page.add_redact_annot(r, fill=fill, cross_out=False)
  1120→                    pending_visible.append((r, size, fontfile, rgb))
  1121→                else:
  1122→                    page.add_redact_annot(r, text=replace, fontsize=size, fontname="helv",
  1123→                                          fill=fill, text_color=rgb, cross_out=False)
  1124→        page.apply_redactions()
  1125→        for r, fs, ff, rgb in pending_visible:
  1126→            _insert_styled_text(page, r, replace, fs, ff, rgb)
  1127→        report.append({"page": i + 1, "replacements": len(hits)})
  1128→
  1129→    if total_hits == 0:
  1130→        raise PDFEngineError(f"لم يُعثر على النص: '{search}'")
  1131→
  1132→    doc.save(str(out), garbage=3, deflate=True)
  1133→    doc.close()
  1134→    return {
  1135→        "success": True,
  1136→        "output": str(out),
  1137→        "total_replacements": total_hits,
  1138→        "details": report,
  1139→        "fonts_used": sorted(fonts_used),
  1140→        "font_mode": font,
  1141→    }

  1144→def _insert_styled_text(page, rect, text: str, fontsize: float, fontfile: str | None, rgb: tuple) -> None:
  1145→    """
  1146→    إدراج النص البديل بشكل مرئي **بنفس الخط المطابق**:
  1147→      - عربي: يُرسم كصورة دقيقة بالخط المطلوب (تشكيل RTL صحيح)
  1148→        + طبقة نص مخفية للبحث والاستخراج — نفس تقنية Acrobat الاحترافية
  1149→      - لاتيني: insert_text بالخط المطابق (نص حقيقي قابل للبحث والنسخ)
  1150→    """
  1151→    if _contains_arabic(text):
  1152→        # 1) الطبقة البصرية: صورة عالية الدقة بالخط المطابق
  1153→        try:
  1154→            import arabic_reshaper
  1155→            from bidi.algorithm import get_display
  1156→            vis = get_display(arabic_reshaper.ArabicReshaper().reshape(text))
  1157→        except Exception:

  1192→        if fontfile:
  1193→            kwargs["fontname"] = "match"

  1454→def pdf_print(
  1455→    path: str,
  1456→    printer: str | None = None,
  1457→    copies: int = 1,
  1458→    pages: str | None = None,
  1459→    duplex: bool = False,
  1460→) -> dict[str, Any]:
  1461→    """
  1462→    إرسال PDF إلى طابعة النظام مباشرة.
  1463→    - Windows: الطباعة عبر نظام Windows
  1464→    - macOS/Linux: عبر نظام CUPS (lp)
  1465→    printer: اسم الطابعة (اختياري — الافتراضية للنظام)، copies: عدد النسخ، duplex: طباعة وجهين.
  1466→    """
  1467→    import platform
  1468→    import subprocess
  1469→
  1470→    p = _p(path)
  1471→    copies = max(1, int(copies))
  1472→    system = platform.system()
  1473→
  1474→    if system == "Windows":
  1475→        try:
  1476→            import os as _os
  1477→            if printer:
  1478→                powershell = (
  1479→                    f'Start-Process -FilePath "{p}" -Verb Print -PassThru | '
  1480→                    f'Out-Null'
  1481→                )
  1482→                # طباعة على طابعة محددة عبر SumatraPDF إن وُجد، وإلا الافتراضية
  1483→                r = subprocess.run(["powershell", "-Command", powershell], capture_output=True, text=True, timeout=60)
  1484→            else:
  1485→                _os.startfile(str(p), "print")
  1486→                r = None
  1487→            return {
  1488→                "success": True,
  1489→                "source": str(p),
  1490→                "printer": printer or "الافتراضية",
  1491→                "copies": copies,
  1492→                "platform": system,
  1493→                "message": "أُرسل الملف إلى الطابعة.",
  1494→            }
  1495→        except Exception as e:
  1496→            raise PDFEngineError(f"فشلت الطباعة على Windows: {e}")
  1497→
  1498→    # macOS / Linux → CUPS
  1499→    lp = shutil.which("lp")
  1500→    if not lp:
  1501→        raise PDFEngineError("نظام الطباعة CUPS غير متوفر على هذا الجهاز.")
  1502→    cmd = [lp, "-n", str(copies)]
  1503→    if printer:
  1504→        cmd += ["-d", printer]
  1505→    if pages:
  1506→        cmd += ["-o", f"page-ranges={pages}"]
  1507→    if duplex:
  1508→        cmd += ["-o", "sides=two-sided-long-edge"]
  1509→    cmd.append(str(p))
  1510→    r = subprocess.run(cmd, capture_output=True, text=True, timeout=60)
  1511→    if r.returncode != 0:
  1512→        raise PDFEngineError(f"فشل إرسال الطباعة: {r.stderr.strip() or r.stdout.strip()}")
  1513→    return {
  1514→        "success": True,
  1515→        "source": str(p),
  1516→        "printer": printer or "الافتراضية",
  1517→        "copies": copies,
  1518→        "platform": system,
  1519→        "message": r.stdout.strip() or "أُرسل الملف إلى الطابعة.",
  1520→    }

  1523→def pdf_impose(path: str, output: str, pages_per_sheet: int = 2) -> dict[str, Any]:
  1524→    """
  1525→    تجهيز PDF للطباعة الاقتصادية: عدة صفحات في الورقة الواحدة (N-up).
  1526→    pages_per_sheet: 2 (جانب-بجانب) أو 4 (شبكة 2×2) أو 6 (2×3) أو 9 (3×3).
  1527→    """
  1528→    grids = {2: (1, 2), 4: (2, 2), 6: (2, 3), 9: (3, 3)}
  1529→    if pages_per_sheet not in grids:
  1530→        raise PDFEngineError("pages_per_sheet يجب أن يكون 2 أو 4 أو 6 أو 9.")
  1531→    rows, cols = grids[pages_per_sheet]
  1532→
  1533→    p = _p(path)
  1534→    out = _new_path(output, f"{p.stem}_{pages_per_sheet}up.pdf")
  1535→    src = pymupdf.open(str(p))
  1536→    dest = pymupdf.open()
  1537→    total = len(src)
  1538→
  1539→    # مقاس الورقة: A4 — أفقي لـ 2-up، رأسي للبقية
  1540→    if pages_per_sheet == 2:
  1541→        sw, sh = 842, 595  # A4 landscape
  1542→    else:
  1543→        sw, sh = 595, 842  # A4 portrait
  1544→
  1545→    cell_w = sw / cols
  1546→    cell_h = sh / rows
  1547→    margin = 8
  1548→
  1549→    for start in range(0, total, pages_per_sheet):
  1550→        sheet = dest.new_page(width=sw, height=sh)
  1551→        for k in range(pages_per_sheet):
  1552→            idx = start + k
  1553→            if idx >= total:
  1554→                break
  1555→            r, c = divmod(k, cols)
  1556→            rect = pymupdf.Rect(
  1557→                c * cell_w + margin,
  1558→                r * cell_h + margin,
  1559→                (c + 1) * cell_w - margin,
  1560→                (r + 1) * cell_h - margin,
  1561→            )
  1562→            sheet.show_pdf_page(rect, src, idx, keep_proportion=True)
  1563→
  1564→    dest.save(str(out), garbage=3, deflate=True)
  1565→    dest.close()
  1566→    src.close()
  1567→    return {
  1568→        "success": True,
  1569→        "output": str(out),
  1570→        "source_pages": total,
  1571→        "pages_per_sheet": pages_per_sheet,
  1572→        "sheets": (total + pages_per_sheet - 1) // pages_per_sheet,
  1573→    }

  1576→def pdf_booklet(path: str, output: str, sheet_size: str = "a4") -> dict[str, Any]:
  1577→    """
  1578→    تجهيز PDF ككتيّب للطباعة على وجهين (saddle-stitch / تجليد سرجي).
  1579→    كل ورقة تحتوي صفحتين؛ تُطبع وجهين ثم تُطوى في المنتصف.
  1580→    """
  1581→    p = _p(path)
  1582→    out = _new_path(output, f"{p.stem}_booklet.pdf")
  1583→    src = pymupdf.open(str(p))
  1584→    total = len(src)
  1585→
  1586→    # حشو إلى أقرب مضاعف لـ 4
  1587→    padded = ((total + 3) // 4) * 4
  1588→
  1589→    def page_at(n: int):  # n يبدأ من 1
  1590→        return (n - 1) if n <= total else None  # None = صفحة فارغة
  1591→
  1592→    dest = pymupdf.open()
  1593→    if sheet_size == "a3":
  1594→        sw, sh = 1191, 842  # A3 landscape
  1595→    else:
  1596→        sw, sh = 842, 595  # A4 landscape
  1597→    half = sw / 2
  1598→
  1599→    # ترتيب الكتيّب الكلاسيكي
  1600→    for i in range(0, padded // 2, 2):
  1601→        left_front = padded - i
  1602→        right_front = 1 + i
  1603→        left_back = 2 + i
  1604→        right_back = padded - 1 - i
