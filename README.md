# محوّل PDF — PDF Convert

منصة عربية بالكامل (RTL) للتعامل مع ملفات PDF والصور: تحويل، دمج، فصل، تدوير، ترقيم، علامة مائية، نصوص، وتحرير — كل الأدوات في مساحة عمل واحدة بواجهة عربية.

## المزايا الحالية

- **مساحة عمل واحدة**: اسحب ملفات PDF أو صور (JPG/PNG/WebP...) وشاهدها في عارض مدمج مع شريط مصغرات الصفحات.
- **أدوات PDF**: تصغير الحجم، دمج، فصل/استخراج صفحات، حذف صفحات، تدوير، إعادة ترتيب، ترقيم الصفحات، ختم/علامة مائية، إضافة نص.
- **أدوات الصور**: تحويل بين الصيغ، تغيير الحجم، الضغط، والمعالجة عبر محرك `sharp`.
- **واجهة عربية أصلية**: اتجاه RTL، كل الأرقام المعروضة إنجليزية (0-9)، رفض واضح للملفات غير المدعومة برسائل عربية.
- **سجل عمل**: ملف `worklog.md` يوثّق كل مرحلة تطوير ومخرجاتها.

## التقنيات

| الطبقة | التقنية |
|---|---|
| الواجهة | Next.js (App Router) + React 19 + Tailwind CSS 4 + shadcn/ui |
| إدارة الحالة | Zustand + @dnd-kit (السحب والإفلات) |
| معالجة PDF في المتصفح | pdf-lib + pdfjs-dist + @pdf-lib/fontkit |
| معالجة الصور | sharp |
| محرك المعالجة الخلفي | Python (`scripts/convert_to_pdf.py`) |
| قاعدة البيانات | Prisma + SQLite (اختيارية — للتشغيل المحلي فقط) |
| مدير الحزم | bun |

## التشغيل المحلي

```bash
# 1) تثبيت الحزم
bun install

# 2) تهيئة قاعدة البيانات (اختياري)
bunx prisma db push

# 3) تشغيل بيئة التطوير
bun run dev
# ثم افتح http://localhost:3000
```

## ملاحظة على مجلد `scripts/build`

ملفات LibreDWG المترجمة (~430MB) مستبعدة من المستودع عمدًا عبر `.gitignore` (تظل موجودة محليًا على جهاز التطوير). محرك المعالجة `scripts/convert_to_pdf.py` يعمل بدونها لأدوات PDF والصور؛ إن احتجت بناء LibreDWG من المصدر فسيتوفر سكربت بناء لاحقًا في نفس المجلد.

## الرخص والاعتمادات المفتوحة

- **pdf-lib / pdfjs-dist / sharp** — رخص مفتوحة (MIT / Apache-2.0).
- **LibreDWG 0.14** — GPLv3: كود المحرك والاختبارات موجود تحت `scripts/`، والملفات المترجمة غير مرفوعة.
- بيانات الاختبار تحت `scripts/samples/` ملفات تجريبية صغيرة.
